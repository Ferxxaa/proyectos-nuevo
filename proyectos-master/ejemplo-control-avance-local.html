📦 Control de Avance - Modo LocalStorage

Esta funcionalidad te permite guardar datos de ejemplo en el navegador sin necesidad de backend.

🚀 Cómo usar el Modo Local:

Paso 1: En la aplicación Angular, haz clic en el botón Modo Servidor en el encabezado para cambiar a Modo Local.
Paso 2: Una vez activado, verás un badge amarillo que dice MODO LOCAL junto al título.
Paso 3: Agrega documentos usando el botón Agregar Documento. Los cambios se guardan automáticamente en tu navegador.
Paso 4: Puedes cerrar y volver a abrir la aplicación - tus datos se mantendrán guardados.
Paso 5: Para limpiar todos los datos, usa el botón Limpiar Local.

✨ Características:

✅ Guardado automático al escribir en cualquier campo
✅ Los datos persisten entre sesiones del navegador
✅ Perfecto para hacer demos y ejemplos
✅ No requiere conexión al servidor
✅ Puedes cambiar entre modo local y servidor cuando quieras
💡 Nota: Los datos guardados en modo local solo están disponibles en tu navegador. No se comparten entre dispositivos ni se sincronizan con el servidor.

🔧 Funciones Disponibles:

ToggleModoLocal(): Activa/desactiva el modo local
GuardarEnLocal(): Guarda manualmente los datos en localStorage
CargarDesdeLocal(): Carga los datos guardados desde localStorage
LimpiarDatosLocales(): Elimina todos los datos guardados localmente
